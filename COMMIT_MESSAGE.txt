feat: integrate with Orchestrator API

Implements integration with external Orchestrator API with following changes:

1. Project-level SSH keys:
   - Created ProjectKeyManager for managing SSH keys at project level
   - Keys generated ONCE per project by orchestrator
   - Private key shared by ALL agents of the project
   - Public key registered in External API → GitHub/GitLab
   - Full test coverage (6/6 tests passing)

2. Task reservation with agent_uuid:
   - Added agent_uuid parameter to ReserveTask()
   - Updated payload: {"reserve_seconds", "agent_uuid"}
   - Added 409 Conflict handling with detailed logging

3. Context passing to agent:
   - Added TASK_ID environment variable
   - Added AGENT_UUID environment variable
   - SSH_PRIVATE_KEY now contains project key (not agent key)

4. Reservation conflicts handling:
   - Graceful handling of 409 Conflict responses
   - New metric: TaskReservationConflictsTotal
   - Tasks are skipped (not failed) on conflict
